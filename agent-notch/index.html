Install in one line

Paste this into PowerShell. No admin rights. It installs the notch and starts it.

PS>irm https://raw.githubusercontent.com/adityarya24/agent-notch/main/install.ps1 | iex

Prefer npm? npm i -g agent-notch then notch. Start at logon with notch autostart.

A glance, not a dashboard

A slim pill sits on the right edge of your screen. Each ring is one agent. It stays out of your way until you need it.

Live quota rings

Session and weekly limits for each agent, read the same way its own CLI reads them. Hover for reset times.

Warned before the wall

A ring turns amber, then red, and you get a notification when an agent crosses your alert threshold.

Sees who's working

A ring glows while that agent is busy, so you can tell at a glance which session is still running.

Works with the agents you already use

Live quota where there's a real source for it. Other CLIs get an icon and the activity glow, never a made-up number.

Questions

Does it send my data anywhere?

No Agent Notch account and nothing sent to me. It reads the sign-in your agent CLIs already keep on your machine and asks each provider for your usage the same way the CLI does. The activity glow uses process and file timestamps only; it never reads your prompts or transcripts.

Does it work on Mac?

Windows today. The macOS port is in progress; the platform groundwork is already in the code.

Will the free version stay free?

Yes. The notch is MIT-licensed open source. Pro adds new features on top; nothing in Free gets taken away.

Is Pro a subscription?

No. You pay once and keep Pro, with updates. The first 100 buyers pay $5; after that it's $9. One license works on two of your computers.

What happens to Pro if I'm offline?

Pro keeps working for 7 days without a connection. The license is checked once a day.
