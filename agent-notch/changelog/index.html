Changelog

Latest: 1.4.2, 27 September 2026

What changed in each release, newest first. Back to Agent Notch.

1.4.2

27 September 2026

Added

  • A refresh button next to Settings at the foot of the rail. It re-reads every provider on demand, the same as "Refresh Quotas Now" in the tray. During a rate-limit cooldown it shows the last known reading instead of forcing another request.

1.4.1

18 September 2026

Changed

  • Suggestions for new tools now spell out the opt-in. One click gives you the icon and glow. Usage % stays a dash until a JSON quota command exists.

1.4.0

18 September 2026

Added

  • Discovery now also recognizes Cline, Continue, Roo Code, Factory Droid, Hermes, Windsurf, Trae, Zed and Kiro. Settings and notch provider discover suggest them. Nothing is added to the notch until you opt in, and usage numbers stay unknown unless you attach a JSON command or a manual snapshot.
  • notch quota (also notch --json) prints the last quota reading as JSON. It reads the cache only. Tokens and raw provider data are never printed.

Changed

  • Smoother motion: collapse and reveal is one spring, rings fade with the slide, quota numbers tick with the arc, and a handoff draws a spark down the rail. Reduce motion turns the new animations off.
  • The open rail is a slimmer half-pill. Settings no longer has a divider.

1.3.8

2 September 2026

Added

  • Agent Notch is on npm. Install with npm i -g agent-notch, or run it once with npx agent-notch.

Changed

  • The handoff notice is now a toast instead of a line inside the rail, so the rail no longer grows and shrinks. It uses the destination agent's quota color.
  • Animations share one set of timings, so a ring's fill, color and glow settle together. Reduce motion turns them all off.

Fixed

  • Choosing the Antigravity icon for a custom agent no longer saves the spark icon instead.
  • The quota toast sits right beside the tucked rail instead of far from it.
  • Opening and closing Settings no longer shifts the notch.
  • The live-agent glow is no longer cut off flat at the edges, and the top and bottom rings no longer bleed into the rail border.
  • The quota toast, settings panel and hover card now animate in.
  • The collapse chevron gutter is narrower.

1.3.7

2 September 2026

Fixed

  • The hover card is no longer clipped at the edge of the window.

1.3.6

2 September 2026

Fixed

  • The working-agent glow no longer washes over the collapse chevron.

1.3.5

2 September 2026

Fixed

  • The working-agent pulse is visible again, and the icon itself glows with it.

1.3.4

2 September 2026

Fixed

  • The working-agent pulse no longer lights up neighboring icons or washes out its own percentage label.

1.3.3

2 September 2026

Fixed

  • The Grok card now uses Grok's own mark instead of the X logo.

1.3.2

2 September 2026

Fixed

  • The Claude card no longer goes grey with "refresh failed" during normal use. When Anthropic rate-limits the request, Notch now keeps showing the last good reading for up to 15 minutes instead of blanking.
  • The Antigravity card now uses the Antigravity mark instead of the Gemini spark.

1.3.1

1 September 2026

Fixed

  • The collapse chevron has its own space and no longer overlaps provider icons.

1.3.0

1 September 2026

Added

  • Add your own tools with notch provider add, plus list, remove and detection-only discover commands.
  • Discovery for Aider, GitHub Copilot, Amp, Goose, Crush, Qwen and ZCode, in Settings and the CLI.

Changed

  • The tucked rail is a quota-colored jewel instead of a plain chevron.
  • When the notch is visible, quota alerts show as a toast inside the rail. Windows toasts are used only when the window is hidden.
  • Codex uses the official OpenAI logomark.
  • Hover cards wait a beat before swapping, dragging lifts the ring, and the rail no longer shifts on hover.

Fixed

  • The tucked jewel follows each ring's own alert threshold instead of assuming 80%.

1.2.1

1 September 2026

Fixed

  • Open but idle Claude, Gemini, Grok, Cursor and OpenCode sessions no longer keep the activity ring glowing.

1.2.0

1 September 2026

Added

  • A desktop notification when a quota crosses your alert threshold while the notch is tucked or hidden. Click it to reveal the notch. Turn it off with Notify when tucked in Settings.
  • The activity glow works for every supported CLI at once, including custom ones.

Changed

  • The last good quota reading now survives restarts for up to 24 hours and is marked stale until refreshed.
  • Custom tools keep activity detection separate from an optional JSON quota command.

Fixed

  • Grok now tells a signed-in session with no quota apart from an expired sign-in.
  • Codex personal 5-hour and weekly windows, and Team weekly-only plans, are labeled correctly.

Privacy

  • Saved quota readings keep display fields only. Activity detection reads process and session metadata, never prompts or transcripts.

1.1.0

31 August 2026

Added

  • Drag to reorder rings. The first four stay in view and extra rings scroll underneath.
  • Healthy (green) percentages use the same color as the ring.

Changed

  • The collapse control is a chevron in the rail: right to tuck, left to pull back out.
  • The activity glow uses the working ring's own color and stays inside the pill. The green pip is gone.
  • Content in the overlay is vertically centered.

1.0.1

31 August 2026

Fixed

  • Settings and runtime files moved out of the install folder, with your old config carried over.
  • notch status, stop and restart work reliably, including after upgrades.
  • Disabled providers are no longer queried.
  • Expired Claude sign-ins are left alone. Notch asks Claude Code to refresh them.
  • Stale quota values are clearly marked and expire after five minutes.
  • Your alert threshold and each provider's quota-window labels are now applied.

Added

  • A slim curved grip that tucks the notch to the screen edge.

Security

  • Moved to Electron 44 with a sandboxed window, blocked navigation and permissions, and a strict content security policy.
  • No more Google Fonts requests at runtime.
  • Custom quota commands now come with a warning, since they run on your machine.
